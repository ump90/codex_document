### 功能成熟度

Source: [Feature Maturity](https://developers.openai.com/codex/feature-maturity.md)

一些 Codex 功能会带有成熟度标签发布，帮助你了解每项功能的可靠程度、可能发生的变化，以及可以期待的支持级别。

| 成熟度            | 含义                                                                          | 建议                                                      |
| ----------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------- |
| 开发中            | 尚未可用。                                                                    | 不要使用。                                                |
| 实验性            | 不稳定，OpenAI 可能会移除或更改它。                                           | 使用风险自负。                                            |
| Beta              | 已准备好进行广泛测试；大多数方面已完整，但某些方面可能会根据用户反馈而变化。 | 适合大多数评估和试点；预计会有小幅变化。                  |
| 稳定              | 完全支持、有文档说明，并准备好广泛使用；行为和配置会随时间保持一致。         | 可安全用于生产；移除通常会经过弃用流程。                  |
