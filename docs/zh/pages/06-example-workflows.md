### 示例工作流

Source: [Workflows](https://developers.openai.com/codex/workflows.md)

当你把 Codex 当作拥有明确上下文和清晰“完成”定义的队友时，它的效果最好。
本页给出 Codex IDE 扩展、Codex CLI 和 Codex cloud 的端到端工作流示例。

如果你刚开始使用 Codex，请先阅读 [提示](https://developers.openai.com/codex/prompting)，然后回到这里查看具体做法。

#### 如何阅读这些示例

每个工作流都包含：

- **适用场景**，以及最适合的 Codex 使用界面（IDE、CLI 或 cloud）。
- **步骤**，包含示例用户提示。
- **上下文说明**：Codex 会自动看到什么，以及你应该附加什么。
- **验证**：如何检查输出。

> **注意：** IDE 扩展会自动把你打开的文件作为上下文包含进来。在 CLI 中，你通常需要明确提及路径（或使用 `/mention` 和 `@` 路径自动补全附加文件）。

---

#### 解释代码库

当你正在入职、接手某个服务，或试图理解协议、数据模型或请求流程时使用此工作流。

#### 做法：在 IDE 中解释代码库

1. 打开最相关的文件。
2. 选择你关心的代码（可选但推荐）。
3. 提示 Codex：

   ```text
   解释请求如何流经所选代码。

   包括：
   - 所涉及每个模块职责的简短总结
   - 哪些数据在何处被验证
   - 修改这里时需要注意的一两个“坑”
   ```

验证：

- 要求提供一个你可以快速验证的图示或检查清单：

```text
将请求流程总结为编号步骤列表。然后列出涉及的文件。
```

#### 做法：在 CLI 中解释代码库

1. 启动交互式会话：

   ```bash
   codex
   ```

2. 附加文件（可选）并提示：

   ```text
   我需要理解此服务使用的协议。阅读 @foo.ts @schema.ts，并解释 schema 和请求/响应流程。重点关注必填字段与可选字段，以及向后兼容规则。
   ```

上下文说明：

- 你可以在输入框中使用 `@` 从工作区插入文件路径，或使用 `/mention` 附加特定文件。

#### 修复 bug

当你有一个可以在本地复现的失败行为时使用此工作流。

#### 做法：在 CLI 中修复 bug

1. 在仓库根目录启动 Codex：

   ```bash
   codex
   ```

2. 给 Codex 一个复现步骤，以及你怀疑的文件：

   ```text
   Bug：点击设置页面上的 "Save" 有时会显示 "Saved"，但不会持久化变更。

   复现：
   1) 启动应用：npm run dev
   2) 前往 /settings
   3) 切换 "Enable alerts"
   4) 点击 Save
   5) 刷新页面：开关被重置

   约束：
   - 不要改变 API 形状。
   - 保持修复最小化，并在可行时添加回归测试。

   先在本地复现该 bug，然后提出补丁并运行检查。
   ```

上下文说明：

- 由你提供：复现步骤和约束（这些比高层描述更重要）。
- 由 Codex 提供：命令输出、发现的调用点，以及它触发的任何堆栈跟踪。

验证：

- Codex 应该在修复后重新运行复现步骤。
- 如果你有标准检查流水线，请让它运行：

```text
修复后，运行 lint 和最小相关测试套件。报告命令和结果。
```

#### 做法：在 IDE 中修复 bug

1. 打开你认为 bug 所在的文件，以及其最近的调用方。
2. 提示 Codex：

   ```text
   找出导致 "Saved" 显示但变更没有持久化的 bug。提出修复后，告诉我如何在 UI 中验证它。
   ```

#### 编写测试

当你想非常明确地指定要测试的范围时使用此工作流。

#### 做法：在 IDE 中编写测试

1. 打开包含该函数的文件。
2. 选择定义该函数的行。从命令面板中选择 "Add to Codex Thread"，将这些行添加到上下文。
3. 提示 Codex：

   ```text
   为这个函数编写一个单元测试。遵循其它测试中使用的约定。
   ```

上下文说明：

- 由 "Add to Codex Thread" 命令提供：所选行（这是“行号”范围），以及打开的文件。

#### 做法：在 CLI 中编写测试

1. 启动 Codex：

   ```bash
   codex
   ```

2. 使用函数名提示：

   ```text
   为 @transform.ts 中的 invert_list 函数添加测试。覆盖正常路径和边界情况。
   ```
