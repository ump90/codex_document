### 开源

Source: [Open Source](https://developers.openai.com/codex/open-source.md)

OpenAI 以开放方式开发 Codex 的关键部分。这些工作位于 GitHub 上，因此你可以跟踪进展、报告问题并贡献改进。

如果你维护一个被广泛使用的开源项目，或想提名维护重要项目的维护者，也可以 [申请 Codex for OSS 计划](https://developers.openai.com/community/codex-for-oss)，以获得 API credits、带 Codex 的 ChatGPT Pro，以及对 Codex Security 的选择性访问。

#### 开源组件

| 组件                        | 位置                                                                                              | 说明                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Codex CLI                   | [openai/codex](https://github.com/openai/codex)                                                   | Codex 开源开发的主要位置 |
| Codex SDK                   | [openai/codex/sdk](https://github.com/openai/codex/tree/main/sdk)                                 | SDK 源码位于 Codex 仓库中 |
| Codex App Server            | [openai/codex/codex-rs/app-server](https://github.com/openai/codex/tree/main/codex-rs/app-server) | App-server 源码位于 Codex 仓库中 |
| Skills                      | [openai/skills](https://github.com/openai/skills)                                                 | 扩展 Codex 的可复用 skills |
| IDE 扩展                    | -                                                                                                 | 不开源 |
| Codex web                   | -                                                                                                 | 不开源 |
| 通用云环境                  | [openai/codex-universal](https://github.com/openai/codex-universal)                               | Codex cloud 使用的基础环境 |

#### 在哪里报告问题和请求功能

使用 Codex GitHub 仓库为各 Codex 组件提交错误报告和功能请求：

- 错误报告和功能请求：[openai/codex/issues](https://github.com/openai/codex/issues)
- 讨论论坛：[openai/codex/discussions](https://github.com/openai/codex/discussions)

提交 issue 时，请尽可能包含你正在使用的组件（CLI、SDK、IDE 扩展、Codex web）和版本。
